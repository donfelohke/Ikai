# IKAI — Study protocol skeleton

## Record for any experiment

1. Question  
2. Method  
3. Data classes collected (prefer none personal)  
4. Consent / opt-out  
5. Retention and deletion  
6. Results vs non-results  
7. Risks and mitigations  
8. Status label (RESEARCH)  

## Privacy threat model (draft)

Assume devices can be lost, accounts phished, and logs over-retained. Default: minimise data, encrypt at rest when storing anything sensitive, never commit secrets.

## Open work

Full annotated bibliography and formal threat model remain corpus/PR tasks where drafted.
