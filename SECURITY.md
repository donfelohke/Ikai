# IKAI Security Policy

Report security or privacy vulnerabilities privately through the contact route on the maintainer's GitHub profile or repository owner page. Include the affected component, impact, and reproduction steps without exposing participant data or secrets.

Never commit credentials, private keys, real participant records, identifiable sensor data, or raw recordings. If a secret is exposed, revoke or rotate it and assess the affected system. If personal data may have been exposed, stop further disclosure and follow the applicable incident process.

IKAI prototypes should make data collection, processing, retention, export, and deletion visible and testable. This document does not assert that automated scanning or branch protection is enabled.
