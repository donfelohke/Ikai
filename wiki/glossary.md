# Glossary

This glossary records working terminology. A definition describes how a term is used in IKAI; it does not imply implementation or scientific consensus beyond the cited context.

| Term | Working definition | Status / caution |
|---|---|---|
| IKAI | Turkana female name meaning “home”; the project's name | Identity fact; not an acronym |
| Reflective Compute | Functional descriptor for research into reflective interfaces and local computation | Research framing |
| Mirror, not a judge | Governing metaphor: support reflection without classification or judgement | Governance principle |
| Reflective computing | Integration of reflective optics, sensing, computation and output in a human-directed environment | Research concept |
| ReflectiveIO | Input/output relationship in a reflective environment | Proposed terminology |
| Bidirectional ReflectiveIO | Camera/touch/sensor input, processing and display/feedback output | Proposed architecture |
| M1 | Initial stationary optical mirror research prototype | Proposed stage |
| Mirror / Glass / Space | Reflective surface, transparent/partially reflective interface, spatial environment | Research taxonomy |
| Mirror XR | Exploration of reflective environments and spatial computing | Research direction |
| REFLECTIVE | Proposed semantic framing for observation, state, intent, capability, authority and memory | Not a released kernel or standard |
| GENJE | Independent embodied creative domain involving music, movement and expression | Cross-domain relationship |
| Choreohacking | Inspecting and modifying choreographic structures as executable creative rules | Research/creative practice |
| LabanLite IR | Proposed computational intermediate representation inspired by selected Laban descriptors | Experimental proposal; not a standard |
| Local-first | Prefer local operation and user-controlled data paths; document exceptions | Architecture principle |
| Participant authority | The person controls participation, capture, retention, sharing and action | Governance principle |

## Naming discipline

Do not use IKAI as an acronym. Do not describe REFLECTIVE, Mirror XR, ReflectiveIO, LabanLite IR or named interaction modes as implemented features unless the implementation and evidence are recorded.
