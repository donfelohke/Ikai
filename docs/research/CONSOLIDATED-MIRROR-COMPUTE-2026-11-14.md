## B. Core proposition

IKAI MIRROR+ is a **persistent, spatially aware, embodied** computing environment with interchangeable optical/digital embodiments.  
WARENA COMPUTE is the **local-first, reproducible** runtime underneath.

Not: fitness subscription clone · clinical device · mandatory cloud AI · Face-ID beauty score.

## C. Architecture layers (summary)

1. Computational foundation (Guix, Shepherd, Guile, native CV)  
2. Perception (camera, optional depth, consent)  
3. Estimates (pose, landmarks — provisional)  
4. Semantic entities (authoritative domain model)  
5. Policy (permissions, retention, app isolation)  
6. Presentation (display / mirror / XR)  
7. Persistence (SQLite + backup)

**Pipeline:** Capture → Pre-process → Estimate → Semantic update → Policy → Present → Persist
