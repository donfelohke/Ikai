# IKAI — Name and Identity Note

**Status:** CANONICAL IDENTITY · owner-confirmed 2026-11-17.

**IKAI is a Turkana female name meaning “home.”** This is the primary identity meaning and must be preserved in all current IKAI documentation and public descriptions. Do not replace it with a technical acronym, invent a competing etymology, or describe “Reflective Compute” as a translation.

**Reflective Compute** is IKAI's functional descriptor. **“A mirror, not a judge”** is its guiding metaphor. The name's meaning and the technical descriptor are distinct.

The idea of home informs the research: belonging, reflection, embodiment, memory, continuity, privacy and a personally controlled environment. It does not prescribe a particular device or imply that a mirror is the only interface.
